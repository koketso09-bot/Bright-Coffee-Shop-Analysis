# Bright-Coffee-Shop-Analysis
Bright Coffee Shop Sales Analysis

Project Overview

This project analyses Bright Coffee Shop's transactional sales data to identify revenue-generating products, peak sales periods, and opportunities to improve business performance using data analytics and visualization.

Stage 1: Planning & Architecture (CANVAS)

Designed a data flow diagram illustrating how data moves from the source through processing, storage, analysis, and reporting. Identified key business questions, required calculations, and expected insights.

Stage 2: Data Processing (Databricks)

Converted the source dataset into CSV format and loaded it into Databricks for processing. Cleaned data types, created transaction time buckets, and calculated total sales revenue using unit price and transaction quantity.

Stage 3: Data Analysis ( Excel)

Used EXCEL to analyse revenue, product performance, quantities sold, and sales trends across time intervals and developed pivot tables and charts to highlight top-performing products and peak sales periods.

Stage 4: Presentation & Recommendations (PowerPoint & Dashoboards)

Presented key findings through visualizations and developed recommendations to improve sales performance. Proposed targeted marketing, better inventory planning, promotion of underperforming products, and automated sales reporting.

Tools & Technologies

- Canvas – Project planning and data architecture
- Databricks – Data processing and transformation
- Databricks SQL – Data querying and analysis
- Microsoft Excel – Pivot tables and charts
- Microsoft PowerPoint – Presentation of findings

Project Deliverables

- Data flow and architecture diagram
- Processed dataset with pivot tables and charts
- SQL analysis script
- PowerPoint presentation with insights and recommendations
